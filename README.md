# Vizyo Digital Signage

**Vizyo Digital Signage** is an **open-source, cross-platform digital signage content management system (CMS)** designed to work flexibly in different scales — from a single standalone screen to fully distributed, centrally managed display networks.

## 🚀 Overview

Vizyo provides a modular and scalable digital signage architecture that can operate in three different modes:

* **Standalone (Self-Service)**
* **Local Network (Peer-to-Peer)**
* **Centralized / Hosted (Cloud or Server-Based)**

This flexibility makes Vizyo suitable for small businesses, schools, offices, and large multi-location deployments.

## ✨ Key Features

### 🖥️ Standalone (Self-Service Mode)

* A **self-contained model** that runs on a single display
* No external server required
* Ideal for kiosks, single screens, or offline usage
* Content is managed directly on the device

### 🔗 Networked Displays (Local Server Mode)

* One display on the **same local network** can act as a **server**
* Other displays connect to it as clients
* Central control without internet dependency
* Perfect for offices, schools, or buildings with multiple screens

### 🌐 Centralized / Hosted Mode

* Run Vizyo on a **hosting environment or dedicated server**
* Manage displays across **different locations via the internet**
* Centralized content scheduling and management
* Scales easily for large organizations

### 🧩 Cross-Platform

* Designed to be platform-independent
* Can be deployed on various operating systems and hardware setups

### 🛠️ Open Source

* Fully open-source
* Customizable and extensible
* Community-driven development

## 🏗️ Architecture Modes

| Mode           | Server Required   | Internet | Use Case                         |
| -------------- | ----------------- | -------- | -------------------------------- |
| Standalone     | ❌ No              | ❌ No     | Single display, kiosk            |
| Local Network  | ✅ One display     | ❌ No     | Multiple screens in one location |
| Hosted / Cloud | ✅ External server | ✅ Yes    | Multi-location deployments       |
